# 식당 목록 일괄 등록 스크립트

동별 식당 목록을 Firestore에 한 번에 등록하는 관리자 전용 스크립트예요.
**밥장이나 팀원이 아니라, 총괄관리자(본인)만 실행하면 됩니다.**

## 1. 준비물: Firebase 서비스 계정 키

이 스크립트는 브라우저용 `firebaseConfig`가 아니라 **관리자 권한 키**가 따로 필요해요 (보안 규칙을 무시하고 바로 쓸 수 있는 키라서).

1. Firebase 콘솔 → 왼쪽 위 톱니바퀴 ⚙️ → "프로젝트 설정"
2. 상단 탭에서 "서비스 계정" 클릭
3. "새 비공개 키 생성" 버튼 클릭 → JSON 파일이 다운로드됨
4. 그 파일 이름을 `serviceAccountKey.json`으로 바꿔서 **이 scripts 폴더 안에** 넣기

⚠️ **이 파일은 절대로 GitHub에 올리면 안 돼요.** (누구나 우리 DB를 마음대로 읽고 쓸 수 있게 되는 키예요)
아래처럼 `.gitignore`에 반드시 추가하세요:
```
scripts/serviceAccountKey.json
```

## 2. 필요한 패키지 설치

```bash
cd scripts
npm init -y
npm install firebase-admin
```

## 3. 식당 목록 채우기

`restaurants-data.js` 파일을 열어서, 동마다 빈 배열 `[]`에 식당 이름을 채워넣으세요.
이태원1동은 이미 채워져 있어요. 다른 동 목록 주시면 같은 파일에 계속 추가하시면 됩니다.

## 4. 실행

```bash
node seed-restaurants.js
```

실행하면 새로 추가된 식당 목록이 콘솔에 쭉 뜨고, 마지막에 "새로 추가 OO개, 건너뜀 OO개"가 출력돼요.

## 참고
- **이미 등록된 식당(이름+동이 같은 경우)은 자동으로 건너뛰어요.** 그래서 새 동 목록을 추가하고 다시 실행해도 기존 데이터가 중복되지 않아요.
- 이 스크립트로 등록한 식당은 기본적으로 어떤 팀에도 "활성화"되어 있지 않아요. 각 팀 밥장이 밥장 관리 화면에서 우리 팀이 쓸 식당을 체크해야 목록에 보여요.
